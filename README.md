# AI-Prompt-Builder
A simple and easy web tool to create, format, and save AI prompts using standard HTML, CSS, and Vanilla JavaScript.
Features
Live Formatting: A clean layout that makes it easy to structure your prompts.

Quick Save: Keep your prompts saved for later use.

100% Vanilla Jaascript: Fast-loading and runs entirely in your browser.

Project Structure:
prompt.html - The main user interface.

prompt.css - Clean styling.

prompt.js - Simple logic for code and saving prompts.
